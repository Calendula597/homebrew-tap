# homebrew-tap

Homebrew tap for [LoongCode](https://github.com/Calendula597/LoongCode).

## Usage

```bash
brew tap Calendula597/tap
brew install loongcode
```

Upgrade:

```bash
brew upgrade loongcode
```

## Maintenance

The formula `loongcode.rb` at the repository root is regenerated and pushed by
`packages/loongcode/script/publish.ts` in the main LoongCode repo on each
release. Manual edits will be overwritten — change the generator instead.
